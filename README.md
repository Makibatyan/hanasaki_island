## 課題

- 方言から標準語：大事な書類やレポートを書く人、地元外の大学に通っている人
- 標準語から方言：旅行先の方言を知りたい人

## 解決方法

どうやって解決しますか？特徴を3つまで。

- 方言から標準語にする際に、「これは〇〇の方言です」と表示する。
- 方言先を複数選択可能にすることで各地域の方言を簡単に見比べることができる。
